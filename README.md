
🌈 Emotions Explorer

About the Project

Emotions Explorer is an interactive, full-stack web application designed to help young children, including children with developmental disabilities, practice recognizing, understanding, and responding to different emotions.

Caregivers can create personalized scenarios based on everyday situations, and children can respond by selecting an emotion picture that represents how they might feel.

The goal is to make learning about emotions fun, interactive, and accessible while encouraging emotional awareness and communication.

How It Works

A child or caregiver reads a scenario displayed on the screen.

The child selects an emotion picture that represents how they feel or would respond.

The application displays the child's selected emotion.

The child clicks Next Question to practice with another scenario.

Caregivers can add personalized scenarios to support the child's individual learning needs.

Features

Emotion Recognition: Children practice identifying emotions using colorful pictures.

Interactive Scenarios: Children respond to everyday situations by selecting an emotion.

Caregiver Customization: Caregivers can create personalized scenarios.

CRUD Functionality: Caregivers can create, read, update, and delete scenarios.

Emotion Picture Bank: Nine emotion images help children recognize different feelings.

Instant Feedback: The application displays the emotion selected by the child.

Simple Interface: A beginner-friendly layout designed to make navigation easier for young children.

Tech Stack

Frontend

HTML5 – Structures the application.

CSS3 – Styles the interface and emotion picture grid.

JavaScript – Handles emotion selections, displays responses, and changes questions.

EJS – Dynamically displays caregiver-created scenarios.

Bootstrap – Provides additional styling and layout support.

Backend

Node.js – Runs the server-side application.

Express.js – Handles server routes and HTTP requests.

MongoDB – Stores caregiver-created scenarios.

Mongoose – Supports MongoDB connectivity and data management.

CRUD Functionality

Emotions Explorer allows caregivers to manage personalized learning scenarios.

Operation

Function

Create

Add a new scenario

Read

Display saved scenarios

Update

Edit an existing scenario

Remove a scenario

All caregiver-created scenarios are saved in MongoDB.

Purpose

I created Emotions Explorer because I am passionate about building accessible technology for children with developmental disabilities.

My goal was to develop a simple educational application that helps children practice emotional recognition and communication while giving caregivers the ability to personalize the learning experience.

This project also allowed me to strengthen my skills in full-stack development, JavaScript, Express.js, MongoDB, and CRUD operations.
